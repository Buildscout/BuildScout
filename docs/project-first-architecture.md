# BuildScout Project-First Architecture

BuildScout is a construction opportunity intelligence platform. A project becomes useful as soon as trustworthy public/licensed source data is available; company enrichment is secondary and opportunistic.

## Universal workflow
Source adapter -> normalize -> validate provenance -> publish project -> attach authorized/public documents -> identify project participants -> score opportunity -> research only high-value companies/contacts -> recommend next action -> track lifecycle.

## Customer types
General contractors; subcontractors and specialty installers; suppliers/distributors; building-product manufacturers; owners/developers; architects; engineers; construction service providers.

## Differentiation
Compete on decision speed and cross-role intelligence: one project graph, source-backed evidence, earlier lifecycle visibility, trade-specific scoring, explainable recommendations, AI project briefs, relationship history, project-change alerts, and no requirement for a giant contact database before value appears.

## Scaling
Every city is an adapter, not a separate product. Each adapter implements fetch -> normalize -> validate provenance -> persist. Search, scoring, documents, alerts, pipeline, company graph, and AI remain shared.

## Rollout
Launch: Dallas-Fort Worth, Austin, Chicago. Next: Houston, San Antonio, Phoenix, Atlanta, Denver, Miami-Fort Lauderdale, Charlotte, Nashville, Tampa. Expand nationally only after source authority, terms, update cadence, field coverage, and document availability are reviewed.

## Data policy
Prefer official public records, licensed feeds, authorized public documents, and company-published information. Preserve source URL, source record ID, observation time, and confidence. Never manufacture missing contacts or project facts.

## MVP
P0: project discovery/search, project detail, source evidence, project team, documents/plans, filters, saved searches, alerts, pipeline, opportunity score.
P1: company graph, contact research, AI project brief, bid/ITB workflows, collaboration.
P2: takeoff/estimating integrations, prequalification, advanced bid management, CRM/ERP integrations.
