# BuildScout MVP

A frontend MVP for a construction intelligence SaaS.

## Run locally
Open `index.html` in a modern browser.

## Included
- DFW construction opportunity map (demo data)
- Search/filtering
- Project details
- Opportunity scores
- Saved projects
- Sales pipeline
- Alerts
- Admin dashboard
- Responsive UI
- Local browser persistence
